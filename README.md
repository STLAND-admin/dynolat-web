# DynOLAT Website

This repository is the ready-to-serve static website. GitHub Pages publishes the files from the repository root; there is no build or Python step.

- `index.html`: main project page.
- `project-source.html`: project insights page.
- `styles.css`, `project-source.css`, `script.js`: page styling and interaction.
- `assets/`: the paper, diagrams, fonts, and videos used by the pages.

The model code is not released yet. The dataset link on the page points to the gated ZJU_OLAT dataset. No repository-wide reuse license is included.
