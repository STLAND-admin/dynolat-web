# DynOLAT Project Website

Static project page for DynOLAT, including the paper and supplementary video, project insights, and additional relighting results.

## Preview locally

Python 3 is sufficient; no package installation or build step is required.

```sh
python3 preview.py --open
```

The preview server supports byte-range requests for video playback.

## Main files

- `index.html`, `styles.css`, `script.js`: main project page.
- `project-source.html`, `project-source.css`: the insights page.
- `assets/`: files referenced by the pages, including the paper, diagrams, fonts, and web-ready videos.

The model code is not released yet. The dataset link on the page points to the gated ZJU_OLAT dataset.
